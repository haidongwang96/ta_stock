# 单股票滚动窗口打分系统使用指南

## 📋 概述

`single_stock_rolling_score.py` 基于技术指标打分系统，对单个股票进行历史滚动窗口分析，评估打分系统对未来走势的预判能力。

### 核心特性

- ✅ **预判性对齐**：第N天的得分对应第N+1天的涨跌幅，评估预测能力
- ✅ **双数据源支持**：支持在线Tushare和本地数据库
- ✅ **多维度输出**：CSV数据、文本报告、可视化图表
- ✅ **信号识别**：自动识别买卖信号和趋势变化

---

## 🚀 快速开始

### 方式一：使用在线Tushare（默认）

```bash
python scripts/single_stock_rolling_score.py --code 000001.SZ --name 平安银行
```

**优点**：无需配置，立即可用
**缺点**：速度较慢，依赖网络和API配额

### 方式二：使用本地数据库（推荐）⭐

```bash
python scripts/single_stock_rolling_score.py --code 600519.SH --num-windows 60 --db
```

**优点**：
- 速度快100倍+
- 不消耗Tushare API配额
- 不依赖网络连接

**前置条件**：
1. 已配置本地数据库（参考 `readme/DATABASE_README.md`）
2. 数据库中有该股票的历史数据

## 📖 详细使用

### 命令行参数说明

| 参数 | 必需 | 说明 | 默认值 |
|------|------|------|--------|
| `--code` | ✅ | 股票代码（如 000001.SZ） | - |
| `--name` | ❌ | 股票名称（可选） | 与code相同 |
| `--end-date` | ❌ | 结束日期（YYYYMMDD） | 今天 |
| `--num-windows` | ❌ | 分析的交易日数量 | 30 |
| `--indicator-window` | ❌ | 技术指标计算窗口（天） | 60 |
| `--use-local-db` | ❌ | 使用本地数据库 | False |
| `--output-dir` | ❌ | 输出目录 | rolling_scores_results |

### 使用示例

#### 1. 基础分析（使用本地数据库）

```bash
python scripts/single_stock_rolling_score.py \
    --code 000001.SZ \
    --name 平安银行 \
    --use-local-db
```

#### 2. 分析最近60个交易日

```bash
python scripts/single_stock_rolling_score.py \
    --code 000001.SZ \
    --use-local-db \
    --num-windows 60
```

#### 3. 使用更长的技术指标窗口（更准确）

```bash
python scripts/single_stock_rolling_score.py \
    --code 000001.SZ \
    --use-local-db \
    --num-windows 60 \
    --indicator-window 120
```

#### 4. 指定结束日期

```bash
python scripts/single_stock_rolling_score.py \
    --code 000001.SZ \
    --use-local-db \
    --end-date 20241130
```

#### 5. 自定义输出目录

```bash
python scripts/single_stock_rolling_score.py \
    --code 000001.SZ \
    --use-local-db \
    --output-dir my_analysis_results
```

## 🔍 预判性对齐说明

### 什么是预判性对齐？

传统方式：第N天的得分 ← 对应 → 第N天的涨跌幅（描述现状）
**本系统**：第N天的得分 → 预测 → 第N+1天的涨跌幅（评估预判能力）

### 为什么这样设计？

1. **评估预测价值**：如果打分系统有效，高分应该对应次日上涨
2. **模拟真实交易**：交易者在第N天收盘后看到信号，第N+1天才能操作
3. **回测更准确**：避免"未来函数"陷阱

### 示例

```
日期      | 得分 | 预测日期 | 次日涨跌幅
2024-01-15 | +8  | 2024-01-16 | +2.3%  ✅ 预判正确
2024-01-16 | +6  | 2024-01-17 | -0.5%  ❌ 预判失败
2024-01-17 | -5  | 2024-01-18 | -1.8%  ✅ 预判正确
2024-01-18 | +2  | 2024-01-19 | N/A    ⏸️ 最新一天，无次日数据
```

## 📈 得分解读

### 得分区间

| 总分范围 | 等级 | 建议 |
|---------|------|------|
| ≥ +8 | 强烈看多 ⭐⭐⭐ | 考虑买入或持有 |
| +5 ~ +7 | 看多 ⭐⭐ | 可考虑逢低买入 |
| +2 ~ +4 | 偏多 ⭐ | 谨慎关注 |
| -1 ~ +1 | 中性 | 观望 |
| -4 ~ -2 | 偏空 ⚠️ | 注意风险 |
| -7 ~ -5 | 看空 ⚠️⚠️ | 考虑减仓 |
| ≤ -8 | 强烈看空 ⚠️⚠️⚠️ | 建议止损 |

### 关键信号

| 信号 | 含义 |
|------|------|
| ⬆️得分转正 | 从负分区间进入正分区间（金叉） |
| ⬇️得分转负 | 从正分区间进入负分区间（死叉） |
| ⬆️突破看多区间 | 得分突破+5（强势信号） |
| ⬇️跌破看空区间 | 得分跌破-5（弱势信号） |
| ⬆️得分大涨(+X) | 单日得分大幅上升（≥5分） |
| ⬇️得分大跌(-X) | 单日得分大幅下降（≤-5分） |
| 📈连续上升 | 连续3天得分上升（趋势形成） |
| 📉连续下降 | 连续3天得分下降（趋势形成） |

## ⚙️ 参数调优建议

### `num-windows`（分析窗口数）

- **30天**（默认）：适合短期分析
- **60天**：适合中期分析
- **120天**：适合长期回测

### `indicator-window`（指标计算窗口）

- **60天**（默认）：适合大多数情况
- **120天**：适合长期趋势分析，指标更平滑
- **建议**：不小于60天，否则技术指标可能不准确

## ❓ 常见问题

### Q1: 为什么要使用本地数据库？

**A**:
- 速度快100倍+（从秒级到毫秒级）
- 不消耗Tushare API配额（免费账户每分钟只能调用200次）
- 不依赖网络，稳定可靠

### Q2: 如何配置本地数据库？

**A**: 参考 `readme/DATABASE_README.md` 进行配置

### Q3: 最新一天的"次日涨跌幅"为什么是N/A？

**A**: 因为采用预判性对齐，第N天的得分预测第N+1天的涨跌。最新一天还没有"次日"数据，所以显示N/A。

### Q4: 如何评估打分系统的预判准确性？

**A**: 查看图表中的"得分预判性分析"子图：
- **相关系数 > 0.3**：有一定预判能力
- **相关系数 > 0.5**：预判能力较强
- **趋势线斜率 > 0**：得分与次日涨跌呈正相关

### Q5: 分析需要多长时间？

**A**:
- **本地数据库**：30个窗口约1-3秒
- **在线Tushare**：30个窗口约30-60秒（受网络和API限制）

## 📝 技术指标说明

系统使用以下5大类技术指标：

1. **趋势类**：MA、MACD、SAR
2. **动量类**：RSI、KDJ、CCI、MFI
3. **波动类**：ATR、布林带、波动率
4. **成交量类**：成交量、OBV、量价关系
5. **形态类**：K线形态、背离

详细打分规则参考 `scripts/daily_stock_scoring.py`
