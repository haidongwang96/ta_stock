# 数据库功能更新日志

## v1.2 (2025-01-06) - 最新日期筛选逻辑

### 🔄 改进：`daily_stock_scoring.py` 使用最新日期而非共同日期

**原逻辑（v1.1）**：
- 查找所有股票**共同的最新日期**（最早的最新日期）
- 使用这个共同日期作为基准
- 所有股票都参与分析

**新逻辑（v1.2）**：
- 查找所有股票中**最新的日期**（最晚的日期）
- 自动排除未更新到最新日期的股票
- 只对有最新日期数据的股票进行打分

### 💡 为什么改进？

**场景示例**：
- 股票池有120只股票
- 其中105只股票数据更新到 2025-01-06
- 剩余15只股票数据停留在 2025-01-05

**原逻辑**：
- 使用 2025-01-05 作为基准日期
- 所有120只股票都用 2025-01-05 的数据打分
- **问题**：丢失了最新一天的数据！

**新逻辑**：
- 使用 2025-01-06 作为基准日期
- 自动排除15只未更新的股票
- 105只股票使用最新的 2025-01-06 数据打分
- **优点**：始终使用最新数据！

### 🔧 使用方法

**无需修改命令**，只需确保使用 `--use-local-db` 参数：

```bash
# 自动使用最新日期并筛选股票
python daily_stock_scoring.py --pool stock_pool_example.txt --use-local-db
```

### ✅ 优点

1. ✅ **始终使用最新数据**：不会因为部分股票未更新而丢失最新日期
2. ✅ **自动筛选**：无需手动剔除未更新的股票
3. ✅ **清晰提示**：明确显示哪些股票被排除
4. ✅ **灵活适应**：适应不同股票更新进度差异
