# 更新说明 - advanced_technical_analysis.py

## 2025-10-28 更新

### 新增功能

#### 1. 每日详细指标输出
- 新增 `print_daily_indicators()` 方法
- 输出日期范围内每一天的所有技术指标值
- 格式化显示，便于查看每日变化趋势

#### 2. 日志文件自动保存
- 类似 `technical_analysis.py` 的日志保存机制
- 使用 `TeeOutput` 类同时输出到控制台和文件
- 每个股票生成独立的 `.txt` 日志文件

### 输出文件说明

现在每个股票分析会生成两个文件：

1. **CSV数据文件**：`advanced_analysis_{股票代码}.csv`
   - 包含所有原始数据和计算的指标值
   - 适合进一步数据分析或导入其他工具

2. **TXT日志文件**：`advanced_analysis_{股票代码}.txt`
   - 包含完整的分析报告
   - 汇总报告（最新状态和建议）
   - 每日详细指标（逐日输出所有指标）

### 每日指标输出内容

每个交易日包含以下信息：

#### 价格数据
- 开盘、最高、最低、收盘价
- 日涨跌幅

#### 成交量指标
- 成交量
- 量比（放量/缩量/正常）

#### 趋势指标
- 移动均线（MA5/10/20/60）
- MACD（DIF、DEA、柱状图）及状态
- SAR（抛物线指标）

#### 动量指标
- RSI（超买/超卖/正常）
- KDJ（K值、D值、J值）
- CCI（商品通道指数）

#### 波动指标
- 布林带（上轨、中轨、下轨、带宽）
- ATR（平均真实波幅）

#### 资金流指标
- OBV（能量潮）及趋势
- MFI（资金流量指数）
- VWAP（成交量加权平均价）

#### 支撑阻力
- 20日支撑位和阻力位
- 枢轴点（Pivot）
- S1/S2（支撑位）、R1/R2（阻力位）

#### 交易信号
- 买入信号
- 卖出信号
- 信号强度
- 背离信号

### 使用示例

```bash
# 分析单个股票，输出最近10天的每日指标
python advanced_technical_analysis.py --code 000001.SZ --days 100 --report_days 10

# 批量分析，每个股票输出最近5天的每日指标
python advanced_technical_analysis.py --pool stock_pool.txt --batch --days 60 --report_days 5
```

### 参数说明

- `--report_days`：控制输出多少天的每日详细指标
  - 默认值：20天
  - 建议：5-30天（太多会使文件过大）
  - 注意：这个参数同时影响汇总报告和每日详细输出

### 文件大小估算

- 每日详细指标约占 1KB
- 10天数据：约 10KB
- 30天数据：约 30KB
- 完整报告（含汇总）：通常 5-50KB

### 与 technical_analysis.py 的对比

| 功能 | technical_analysis.py | advanced_technical_analysis.py (更新后) |
|------|----------------------|----------------------------------------|
| 日志保存 | ✅ 有 | ✅ 有（新增） |
| 每日输出 | ✅ 有（简单） | ✅ 有（详细，新增） |
| 指标数量 | 少（MFI、OBV等） | 多（15+个指标） |
| 输出格式 | 基础 | 分层次、分类别 |
| 批量分析日志 | ✅ 有 | ✅ 有（每个股票独立文件） |

### 注意事项

1. **数据要求**
   - 某些指标需要足够的历史数据
   - 建议使用至少60天的数据进行分析
   - 数据不足时会显示警告信息

2. **性能考虑**
   - 批量分析大量股票时可能需要较长时间
   - 每个股票的日志文件独立生成，不会相互影响

3. **文件管理**
   - 重复分析会覆盖原有文件
   - 建议定期备份重要分析结果
   - 所有文件保存在 `advanced_analysis_results/` 目录

### 错误处理改进

- 增强了数据不足时的错误处理
- MACD、布林带等指标在数据不足时会显示警告
- 不会因个别指标失败而中断整体分析
