# 技术指标分析工具说明文档

## 📊 技术指标概览

本工具综合运用多个技术指标进行股票分析，采用**多维度综合验证**的思路，通过价格形态、成交量、资金流等多个维度的共振来生成交易信号。

## 功能概述

这是一个综合技术分析工具，整合了以下功能：

1. **K线形态识别**：识别锤子线、射击之星、十字星、大阳线、大阴线等经典形态
2. **技术指标计算**：
   - MFI (Money Flow Index) - 资金流量指标
   - OBV (On-Balance Volume) - 能量潮指标
3. **成交量分析**：识别放量、缩量，计算量比
4. **交易信号生成**：综合K线、成交量和技术指标生成买卖信号

## 一、核心技术指标详解

### 1. MFI (Money Flow Index) - 资金流量指标

**代码位置:** `technical_analysis.py:89`

**计算方法:**
- 默认周期: 14天
- 综合考虑价格和成交量的动量指标

**含义:**
- 衡量资金流入流出的强度
- 类似于RSI，但加入了成交量因素
- 范围: 0-100

**行为逻辑:**
- **MFI > 80**: 严重超买，资金流入过度，可能面临回调
- **MFI > 70**: 超买区域，警惕做多
- **MFI < 30**: 超卖区域，可能存在反弹机会
- **MFI < 20**: 严重超卖，关注抄底信号

---

### 2. OBV (On-Balance Volume) - 能量潮

**代码位置:** `technical_analysis.py:92`

**计算方法:**
- 累积成交量指标
- 价格上涨日: OBV += 当日成交量
- 价格下跌日: OBV -= 当日成交量

**含义:**
- 通过成交量变化预测价格趋势
- 反映资金的持续流入或流出

**行为逻辑:**
- **OBV上升 + 价格上升**: 健康上涨，量价配合（买入信号）
- **OBV下降 + 价格下降**: 下跌确认，量价同步（卖出信号）
- **OBV > OBV_MA(20日均线)**: 上升趋势
- **OBV < OBV_MA**: 下降趋势

---

### 3. 成交量分析指标

**代码位置:** `technical_analysis.py:158-182`

#### 3.1 成交量均线
- `volume_ma5`: 5日成交量均线
- `volume_ma10`: 10日成交量均线

#### 3.2 量比 (Volume Ratio)
- `volume_ratio = 当日成交量 / 5日均量`

**行为逻辑:**
- **量比 > 1.5**: 放量（成交活跃，关注度高）
- **量比 < 0.7**: 缩量（成交清淡，观望情绪浓）

## 二、K线形态识别

### 4. 锤子线 (Hammer)

**代码位置:** `technical_analysis.py:123-127`

**识别条件:**
- 下影线长度 > 实体的2倍
- 上影线 < 实体的30%
- 实体占总波动比例 > 10%

**含义:**
- 出现在下跌趋势末端，表示下跌动能减弱
- 多方开始反击的信号

**行为逻辑:**
- 单独出现: 弱反转信号
- **配合放量 + MFI超卖**: 强烈买入信号（信号强度+3）

---

### 5. 射击之星 (Shooting Star)

**代码位置:** `technical_analysis.py:130-134`

**识别条件:**
- 上影线长度 > 实体的2倍
- 下影线 < 实体的30%
- 实体占总波动比例 > 10%

**含义:**
- 出现在上涨趋势末端，表示上涨乏力
- 空方开始打压的信号

**行为逻辑:**
- **配合放量 + MFI超买**: 强烈卖出信号（信号强度-3）

---

### 6. 十字星 (Doji)

**代码位置:** `technical_analysis.py:137`

**识别条件:**
- 实体占总波动比例 < 10%

**含义:**
- 多空力量平衡
- 趋势可能发生转折

---

### 7. 大阳线

**代码位置:** `technical_analysis.py:143-147`

**识别条件:**
- 收盘价 > 开盘价（阳线）
- 实体占总波动比例 > 70%
- 日涨幅 > 3%

**含义:**
- 多方力量强劲
- 强势上涨信号

**行为逻辑:**
- **配合放量 + MFI未超买(<70)**: 买入信号（信号强度+2）

---

### 8. 大阴线

**代码位置:** `technical_analysis.py:150-154`

**识别条件:**
- 收盘价 < 开盘价（阴线）
- 实体占总波动比例 > 70%
- 日跌幅 < -3%

**含义:**
- 空方力量强劲
- 强势下跌信号

**行为逻辑:**
- **配合放量**: 卖出信号（信号强度-2）

---

## 三、综合交易信号逻辑

**代码位置:** `technical_analysis.py:184-258`

### 买入信号（强度递减）

1. **锤子线 + 放量 + MFI超卖** → 信号强度 +3
   - 锤子线形态确认
   - 成交量放大（量比 > 1.5）
   - MFI < 30

2. **OBV上升趋势** → 信号强度 +2
   - OBV > OBV_MA
   - 收盘价 > 前一日收盘价

3. **大阳线 + 放量 + MFI未超买** → 信号强度 +2
   - 大阳线形态确认
   - 成交量放大（量比 > 1.5）
   - MFI < 70

4. **MFI超卖 + 价格企稳** → 信号强度 +1
   - MFI < 20
   - 收盘价 > 前一日收盘价

---

### 卖出信号（强度递减）

1. **射击之星 + 放量 + MFI超买** → 信号强度 -3
   - 射击之星形态确认
   - 成交量放大（量比 > 1.5）
   - MFI > 70

2. **OBV下降趋势** → 信号强度 -2
   - OBV < OBV_MA
   - 收盘价 < 前一日收盘价

3. **大阴线 + 放量** → 信号强度 -2
   - 大阴线形态确认
   - 成交量放大（量比 > 1.5）

4. **MFI超买 + 价格滞涨** → 信号强度 -1
   - MFI > 80
   - 收盘价 < 前一日收盘价

---

### 信号强度分类

- **|强度| ≥ 3**: 强烈信号
- **|强度| ≥ 2**: 一般信号
- **强度 > 0**: 偏多信号（买入倾向）
- **强度 < 0**: 偏空信号（卖出倾向）

## 四、核心设计思想

本工具采用 **多维度综合验证** 的分析思路：

### 1. 价格形态（K线）
- 识别关键转折点
- 捕捉市场情绪变化

### 2. 成交量（量比）
- 验证信号的有效性
- 确认市场参与度

### 3. 资金流（MFI/OBV）
- 确认资金动向
- 判断趋势的可持续性

### 4. 多重共振
- 多个条件同时满足才产生强信号
- 降低假信号，提高交易胜率

## 五、使用方法

### 安装依赖

```bash
pip install pandas pandas-ta tushare
```

### 基本用法

```bash
python technical_analysis.py --code 000001.SZ
```

### 完整参数

```bash
python technical_analysis.py \
  --code 000001.SZ \
  --start 20231201 \
  --end 20241231 \
  --days 10 \
  --output analysis_result.csv
```

### 参数说明

- `--code`: 股票代码（必需），格式如 `000001.SZ` 或 `600000.SH`
- `--start`: 开始日期，格式 YYYYMMDD，默认为60天前
- `--end`: 结束日期，格式 YYYYMMDD，默认为今天
- `--days`: 在报告中显示最近N天的详细分析，默认10天
- `--output`: 输出CSV文件路径，如不指定则使用默认命名

## 六、输出文件说明

所有结果保存在 `technical_analysis_results/` 文件夹中：

1. **完整分析数据**: `technical_analysis_{股票代码}_{日期}.csv`

   - 完整的分析报告文本
   - 包含统计信息和强信号汇总

### CSV文件字段说明

- **基础数据**: trade_date, Open, High, Low, Close, Volume
- **技术指标**: MFI, OBV, OBV_MA
- **K线形态**: is_hammer, is_shooting_star, is_doji, is_big_bullish, is_big_bearish
- **成交量分析**: volume_ma5, volume_ratio, is_volume_surge, is_volume_shrink
- **交易信号**: signal, signal_strength

## 十、注意事项

### 1. 数据要求
- **历史数据**: 建议至少获取60天的历史数据，以确保指标计算的准确性
- **Tushare token**: 需要有效的Tushare token（已在代码中配置）

### 2. 指标解读
- 技术指标只是辅助工具，不能作为唯一决策依据
- 应结合多个维度综合判断
- 注意市场整体环境和个股基本面

### 3. 信号特性
- **滞后性**: 技术指标都是基于历史数据计算的，存在一定的滞后性
- **准确性**: 强信号（|强度| ≥ 3）更可靠，但也要注意风险控制
- **市场环境**: 不同的市场环境下，技术指标的有效性可能有所差异

### 4. 风险控制
- 避免在震荡市中频繁操作
- 建议配合止损止盈策略
- 实际交易需要结合基本面分析和严格的风险控制

## 十二、K线图绘制工具使用指南

### 工具说明

`plot_kline.py` 是一个专业K线图绘制工具，采用仿交易软件风格设计（黑色背景），可以将技术分析结果可视化为专业的K线图表。

### 功能特性

- **专业交易软件风格**：黑色背景，红涨绿跌配色方案
- **多窗口布局**：
  - 主图：K线 + 均线（MA5, MA10, MA20, MA60）
  - 副图1：成交量柱状图 + 成交量均线
  - 副图2：MFI资金流量指标（含超买超卖标记）
  - 副图3：OBV能量潮指标（含趋势线）
- **K线形态标注**：自动统计并显示锤子线、大阳线、大阴线等形态
- **交易信号标注**：在K线图上标记买入(B)和卖出(S)信号

### 基本用法

#### 1. 绘制完整技术分析结果（推荐）

```bash
# 从技术分析生成的CSV文件绘制K线图
python plot_kline.py --input technical_analysis_results/technical_analysis_000001.SZ_20241224.csv
```

#### 2. 绘制简单K线数据

```bash
# 从仅包含OHLCV数据的CSV文件绘制（会自动计算均线）
python plot_kline.py --input kline_data.csv --code 000001.SZ
```

### 完整参数说明

```bash
python plot_kline.py \
  --input technical_analysis_000001.SZ_20241224.csv \
  --code 000001.SZ \
  --output my_chart.png \
  --type full
```

### 参数详解

| 参数 | 必需 | 说明 | 默认值 |
|------|------|------|--------|
| `--input` | 是 | 输入文件路径（CSV格式） | 无 |
| `--code` | 否 | 股票代码，用于图表标题 | 从文件名自动提取 |
| `--output` | 否 | 输出图片文件路径 | `technical_analysis_results/{文件名}_professional.png` |
| `--type` | 否 | 数据类型：full/simple/auto | auto（自动检测） |

### 数据类型说明

- **full模式**：输入文件包含完整的技术指标（MFI、OBV等）
  - 适用于 `technical_analysis.py` 生成的CSV文件
  - 会绘制所有技术指标图表

- **simple模式**：输入文件仅包含基础K线数据（OHLCV）
  - 适用于简单的K线数据文件
  - 会自动计算均线，但不显示MFI、OBV等指标

- **auto模式**（默认）：自动检测输入文件类型
  - 根据是否包含MFI等字段自动判断

### 输入文件格式要求

#### Full模式（完整技术分析数据）
必需字段：
```
trade_date, Open, High, Low, Close, Volume, MFI, OBV, OBV_MA
```

可选字段（用于形态标注和信号标记）：
```
is_hammer, is_big_bullish, is_big_bearish, signal, signal_strength
```

#### Simple模式（基础K线数据）
必需字段：
```
trade_date, Open, High, Low, Close, Volume
```

或中文字段名：
```
日期, 开盘价, 最高价, 最低价, 收盘价, 成交量
```
