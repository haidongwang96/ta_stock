# 低位缩量反转策略 - 使用说明

## 📋 策略概述

### 策略定位
**名称**: Low Volume Reversal Strategy（低位缩量反转策略）
**类型**: 底部突破捕捉策略（ACCUMULATION → MARK_UP转折点）
**风格**: 中线波段（持仓周期5-15天）
**收益目标**: 单次+5%（保守）至+8%（强信号）

### 核心思想
在市场底部（ACCUMULATION）向上突破进入上涨阶段（MARK_UP）的转折时刻，捕捉"缩量下跌转放量上涨"的反转信号。

## 🎯 入场逻辑（4层严格筛选）

### 第1层：市场结构确认
- 当前结构为 `ACCUMULATION`（底部横盘吸筹）
- 或刚从 `ACCUMULATION` 转为 `MARK_UP`（底部突破）
- 或 `MARK_UP` 早期（转折后5天内）

### 第2层：低位判断（4重组合，满足3项即可）
1. **布林带**: 价格 < 布林带下轨 × 1.02
2. **RSI**: RSI < 30（超卖）
3. **均线**: 价格 < MA20 或 < MA60
4. **新低**: 创近20日或60日新低

### 第3层：缩量下跌确认（供应枯竭）
- **持续时间**: 5-10个交易日
- **VSA信号**: 出现至少5次 `SUPPLY_DRY_UP`（价跌量缩）信号
- **成交量**: 期间平均volume_multiple < 0.8
- **跌幅**: -2% 至 -15%（温和回调，非暴跌）
- **禁止**: 不出现 `PANIC_SELL`（恐慌抛售）信号

### 第4层：放量上涨确认（4种强度等级）
- **强度3**: 极强放量(>2.5倍) + 连续2天放量 + 突破阻力位
- **强度2**: 强放量(>2.0倍) + (连续放量 或 突破阻力位)
- **强度1**: 基础放量(>1.5倍) + HEALTHY_UP信号
- **强度0**: 仅出现HEALTHY_UP信号（最低标准）

## ⚙️ 风险管理

### 止损设置
- **止损位**: 缩量下跌期间最低点 × 0.98（-2%缓冲）
- **逻辑**: 如果跌破前期低点，说明供应枯竭失败

### 目标位设置
- **保守目标**: 当前价 × 1.05（+5%，强度0-1）
- **积极目标**: 当前价 × 1.08（+8%，强度2-3）

### 风险回报比
- **最小要求**: 2.0（潜在收益 / 潜在亏损 ≥ 2）
- **实际范围**: 通常在2.0-3.0之间

## 🚀 使用方法

### 1. 每日扫描（推荐每天收盘后运行）

```bash
# 扫描完整股票池
python scripts/low_volume_scanner.py --pool pool/stock_pool_all.txt

# 扫描小股票池（测试用）
python scripts/low_volume_scanner.py --pool pool/stock_pool_small.txt

# 测试模式（仅扫描前10只）
python scripts/low_volume_scanner.py --pool pool/stock_pool_all.txt --test
```

### 2. 单只股票分析

```bash
# 基础扫描
python scripts/low_volume_scanner.py --code 688256.SH --name 寒武纪

# 详细输出
python scripts/low_volume_scanner.py --code 688256.SH --name 寒武纪 --verbose

# 生成K线图（待实现）
python scripts/low_volume_scanner.py --code 688256.SH --name 寒武纪 --plot
```

### 3. 回测验证

```bash
# 回测单只股票（最近1年）
python scripts/low_volume_backtest.py --code 688256.SH --name 寒武纪

# 指定时间段回测
python scripts/low_volume_backtest.py --code 688256.SH --start 20240101 --end 20251110

# 自定义输出文件
python scripts/low_volume_backtest.py --code 688256.SH --output my_backtest.txt
```

## 🔧 参数调优

### 配置文件位置
`config/low_volume_reversal_config.py`

### 常用调优参数

#### 1. 低位严格度
```python
LOW_POSITION_CONFIG = {
    'low_condition_min': 3,  # 4个条件满足3个（推荐3-4）
    'rsi_threshold': 30,     # RSI超卖阈值（20-30）
}
```

#### 2. 缩量下跌窗口
```python
SUPPLY_DRY_CONFIG = {
    'min_days': 5,          # 最少天数（3-5）
    'max_days': 10,         # 最多天数（10-15）
    'min_signals': 5,       # 最少信号数（3-7）
}
```

#### 3. 放量确认标准
```python
HEALTHY_UP_CONFIG = {
    'min_volume_multiple': 1.5,     # 基础放量（1.3-1.8）
    'strong_volume_multiple': 2.0,  # 强放量（1.8-2.5）
}
```

#### 4. 风险回报比
```python
RISK_MANAGEMENT = {
    'target_ratio': 1.05,        # 保守目标（1.05-1.10）
    'target_ratio_strong': 1.08,  # 强信号目标（1.08-1.15）
    'min_risk_reward': 2.0,      # 最小风险回报比（1.5-3.0）
}
```

### 调优建议

**追求高胜率（保守）**:
- `low_condition_min = 4`（4个低位条件全满足）
- `min_signals = 7`（更充分的缩量）
- `min_risk_reward = 2.5`（更严格的风险回报比）

**追求高频率（积极）**:
- `low_condition_min = 2`（放宽低位判断）
- `min_signals = 3`（减少缩量要求）
- `min_risk_reward = 1.5`（降低风险回报比门槛）

**平衡模式（推荐）**:
- 使用默认配置即可

## 💡 使用技巧

### 1. 每日工作流程
```bash
# 步骤1：每天收盘后运行扫描
python scripts/low_volume_scanner.py --pool pool/stock_pool_all.txt

# 步骤2：查看报告（low_volume_reports/目录）
# 重点关注强度2-3级信号

# 步骤3：对TOP信号进行人工复核
python scripts/low_volume_scanner.py --code XXXXX.XX --verbose

# 步骤4：（可选）查看历史表现
python scripts/low_volume_backtest.py --code XXXXX.XX
```

### 2. 信号质量判断
- **强度3级**: 最高质量，可直接关注
- **强度2级**: 较好质量，建议结合其他分析
- **强度1级**: 一般质量，谨慎对待
- **强度0级**: 仅供参考，不建议直接操作

### 3. 风险提示
1. **市场环境**: 策略在震荡市和底部区域表现最佳，在单边下跌中效果较差
2. **个股选择**: 优先选择基本面良好、流动性充足的股票
3. **止损纪律**: 严格执行止损，不要因为"便宜"而加仓
4. **仓位控制**: 单只股票不超过20%，总仓位不超过60%
5. **分散投资**: 同时持仓2-4只不同行业的股票，降低风险

## 🔍 常见问题

### Q1: 为什么扫描不到信号？
A: 策略筛选非常严格，需要同时满足4层条件。如果长期无信号，可以：
- 检查股票池是否有效
- 降低部分参数阈值（见参数调优章节）
- 扩大股票池范围

### Q2: 如何判断信号是否可靠？
A: 优先关注以下特征：
- 信号强度 ≥ 2
- 风险回报比 ≥ 2.5
- 市场结构置信度 > 0.7
- 缩量下跌天数 ≥ 6天

### Q3: 回测结果与实盘差异较大？
A: 可能原因：
- 回测使用的是第二天开盘价，实盘可能有滑点
- 回测未考虑涨跌停板限制
- 市场环境变化
- 建议：用最近3-6个月数据验证策略有效性

### Q4: 能否自动交易？
A: 当前版本仅提供信号，不包含自动下单功能。自动交易需要：
- 对接券商API
- 实现风险控制模块
- 考虑涨跌停、流动性等因素
