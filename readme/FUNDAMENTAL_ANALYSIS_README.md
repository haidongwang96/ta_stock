# 基本面分析脚本使用说明

## 概述

`fundamental_analysis.py` 是一个基于Tushare的股票基本面财务分析工具，能够自动获取和分析上市公司的财务数据，计算关键财务指标的同比和环比增长率，并生成详细的分析报告和可视化图表。

## 功能特性

### 核心功能

1. **财务数据获取**
   - 自动从Tushare获取最近4-5个季度的财务数据
   - 包括利润表、资产负债表、现金流量表、财务指标

2. **财务指标分析**
   - **营业收入**：单位自动转换为亿元
   - **盈利能力指标**：毛利率、净利率、ROE、ROA
   - **费用率指标**：销售费用率、管理费用率、研发费用率
   - **偿债能力指标**：资产负债率、流动比率
   - **现金流指标**：销售现金比率、经营现金流比率

3. **增长率计算**
   - **环比增长率**：与上一季度对比
   - **同比增长率**：与去年同期对比
   - 自动处理异常值和缺失数据

4. **多种输出方式**
   - **控制台输出**：使用表格格式直接显示核心指标
   - **TXT详细报告**：保存完整的财务数据和增长率
   - **可视化图表**：6张趋势图展示各项指标变化

### 输入方式

- **单只股票分析**：命令行直接输入股票代码
- **批量分析**：从文本文件读取股票池
- **多进程支持**：批量分析时可配置并发进程数

## 使用方法

### 1. 单只股票分析（默认4个季度）

```bash
python scripts/fundamental_analysis.py 600519.SH
```

**输出：**
- 控制台打印格式化的财务数据表格
- 生成TXT详细报告：`fundamental_results/600519.SH_YYYYMMDD_HHMMSS.txt`
- 生成PNG趋势图：`fundamental_results/600519.SH_YYYYMMDD_HHMMSS_trends.png`

### 2. 自定义季度数量

```bash
# 获取最近6个季度的数据
python scripts/fundamental_analysis.py 600519.SH -n 6

# 获取最近8个季度的数据
python scripts/fundamental_analysis.py 600519.SH -n 8
```

**说明**：
- 默认获取4个季度
- 建议范围：4-8个季度
- 季度越多，趋势分析越全面，但图表会更拥挤

### 3. 批量分析

```bash
# 默认4个季度
python scripts/fundamental_analysis.py -f example_stock_pool.txt

# 指定季度数量
python scripts/fundamental_analysis.py -f stock_pool.txt -n 6
```

**股票池文件格式：**
```
# 注释行以#开头
600519.SH
000858.SZ
600036.SH
```

### 4. 批量分析 + 自定义并发进程数

```bash
# 8个季度，使用8个进程
python scripts/fundamental_analysis.py -f stock_pool.txt -n 8 -w 8
```

**参数说明：**
- `-f, --file`: 股票池文件路径
- `-n, --num-quarters`: 获取的季度数量（默认4）
- `-w, --workers`: 最大进程数（默认4）

### 5. 查看帮助

```bash
python scripts/fundamental_analysis.py --help
```

### 趋势图说明（双Y轴设计）

每张图表采用**双Y轴**设计，在同一张图上同时显示：
- **左轴（折线图）**：显示指标的具体数值
- **右轴（柱状图）**：显示环比增长率（绿色=增长，红色=下降）

**6张图表内容：**

1. **营业收入趋势与环比增长**
   - 折线：营业收入（亿元）
   - 柱状：环比增长率（%）

2. **毛利率趋势与环比变化**
   - 折线：毛利率（%）
   - 柱状：环比变化（百分点）

3. **净利率趋势与环比变化**
   - 折线：净利率（%）
   - 柱状：环比变化（百分点）

4. **ROE趋势与环比变化**
   - 折线：ROE（%）
   - 柱状：环比变化（%）

5. **三费率对比**
   - 销售费用率、管理费用率、研发费用率
   - 三条折线在同一坐标系对比

6. **ROA趋势与环比变化**
   - 折线：ROA（%）
   - 柱状：环比变化（%）

**视觉特点：**
- 🟢 绿色柱状 = 环比增长
- 🔴 红色柱状 = 环比下降
- 📍 **折线数据点上直接标注具体数值** - 无需查看Y轴即可读取准确数值
- 🎯 数值标注带半透明白色背景，确保清晰可读
- 双轴设计便于同时观察绝对值和变化趋势

## 数据说明

### 季度数据获取逻辑

脚本会根据当前月份自动判断最新可获取的季报数据：

- **11月及之后**：Q3数据已公布 (如：20240930, 20240630, 20240331, 20231231)
- **8-10月**：Q2数据已公布
- **5-7月**：Q1数据和上年年报已公布
- **1-4月**：仅上年数据已公布

### 同比/环比计算规则

- **环比增长率**：(本季度指标 - 上季度指标) / |上季度指标| × 100%
- **同比增长率**：(本季度指标 - 去年同期指标) / |去年同期指标| × 100%
- 注意：同比计算需要至少5个季度的数据

### 数据异常处理

- 自动去除Tushare API返回的重复数据
- 不同数据表通过`end_date`字段智能合并
- 缺失数据显示为`nan`或空值

## 技术架构

### 核心类

1. **FundamentalDataFetcher**
   - 职责：初始化Tushare API，获取财务数据
   - 方法：`get_recent_quarters()`, `fetch_financial_data()`

2. **FundamentalAnalyzer**
   - 职责：计算财务指标和增长率
   - 方法：`calculate_metrics()`, `calculate_growth_rates()`, `analyze()`

3. **ResultOutputter**
   - 职责：生成多种格式的输出结果
   - 方法：`print_to_console()`, `save_to_txt()`, `plot_trends()`

### 数据流

```
Tushare API
    ↓
FundamentalDataFetcher (获取原始财务数据)
    ↓
FundamentalAnalyzer (计算指标和增长率)
    ↓
ResultOutputter (生成报告和图表)
```

## 注意事项

1. **Tushare Token**
   - 需要在项目根目录下放置`token.txt`文件
   - 文件中只包含一行：你的Tushare API token

2. **API访问限制**
   - Tushare对API调用频率有限制
   - 批量分析时建议控制进程数（推荐4-8个）
   - 遇到限流错误时可适当降低`-w`参数

3. **数据时效性**
   - 季报数据通常在季度结束后1个月内公布
   - 脚本已内置季报公布时间的判断逻辑
   - 如遇到数据缺失，可能是该季度数据尚未公布

4. **数据准确性**
   - 数据来源于Tushare官方接口
   - 部分指标可能因财报调整而更新
   - 建议定期重新拉取最新数据

## 常见问题

### Q: 为什么某些季度数据是NaN？

A: 可能原因：
1. 该季度的利润表数据尚未公布
2. 公司在该季度没有披露某些财务明细
3. Tushare数据源暂时缺失

### Q: 同比增长率为何只显示最近的季度？

A: 同比计算需要去年同期数据，默认获取5个季度数据，因此只有第1个季度能计算同比。

### Q: 批量分析时如何提高速度？

A: 可以增加`-w`参数，例如：
```bash
python scripts/fundamental_analysis.py -f stock_pool.txt -w 8
```

### Q: 图表中文显示乱码怎么办？

A: 脚本已配置中文字体支持，如仍有问题，请检查系统是否安装了以下字体：
- macOS: Arial Unicode MS
- Windows: SimHei
- Linux: 需手动安装中文字体
