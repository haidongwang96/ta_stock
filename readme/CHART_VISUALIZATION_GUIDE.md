# 基本面分析图表可视化说明

## 📊 图表设计理念

本脚本生成的财务指标趋势图采用**双Y轴设计**，在一张图上同时展示：
1. **具体数值**（折线图） - 观察指标的绝对水平
2. **环比增长率**（柱状图） - 观察指标的变化速度

这种设计让您可以同时看到"现在怎么样"和"变化如何"。

## 📋 各图表详细说明

### 1️⃣ 营业收入趋势与环比增长

**左Y轴（蓝色）**：营业收入（亿元）
- 折线图显示每个季度的营业收入绝对值
- 观察公司收入规模的变化

**右Y轴（灰色）**：环比增长率（%）
- 🟢 **绿色柱状** = 营收环比增长
- 🔴 **红色柱状** = 营收环比下降
- 柱状高度表示增长或下降的幅度

**分析要点**：
- 折线向上 + 绿柱 → 收入增长且加速
- 折线向上 + 红柱 → 收入增长但放缓
- 折线向下 + 红柱 → 收入下降

---

### 2️⃣ 毛利率趋势与环比变化

**左Y轴（紫色）**：毛利率（%）
- 反映产品或服务的盈利能力
- 毛利率 = (营业收入 - 营业成本) / 营业收入

**右Y轴（灰色）**：环比变化（百分点）
- 🟢 绿柱 = 毛利率提升
- 🔴 红柱 = 毛利率下降

**分析要点**：
- 毛利率上升 → 产品竞争力增强或成本控制改善
- 毛利率下降 → 可能面临价格压力或成本上升

---

### 3️⃣ 净利率趋势与环比变化

**左Y轴（橙色）**：净利率（%）
- 反映公司的最终盈利能力
- 净利率 = 净利润 / 营业收入

**右Y轴（灰色）**：环比变化（百分点）
- 🟢 绿柱 = 净利率提升
- 🔴 红柱 = 净利率下降

**分析要点**：
- 净利率持续上升 → 盈利能力增强
- 净利率下降 → 需关注费用控制或其他支出

---

### 4️⃣ ROE趋势与环比变化

**左Y轴（绿色）**：ROE（净资产收益率，%）
- 衡量股东资金的使用效率
- ROE越高，股东回报越好

**右Y轴（灰色）**：环比变化（%）
- 🟢 绿柱 = ROE提升
- 🔴 红柱 = ROE下降

**分析要点**：
- ROE > 15% 通常被认为是优秀
- ROE持续上升说明资本使用效率提高

---

### 5️⃣ 三费率对比

**同一Y轴**：费用率（%）
- 🔵 **销售费用率**（蓝色）：销售费用 / 营业收入
- 🟠 **管理费用率**（橙色）：管理费用 / 营业收入
- 🟢 **研发费用率**（绿色）：研发费用 / 营业收入

**分析要点**：
- 三费率对比可以看出公司的费用结构
- 费用率上升需警惕成本失控
- 研发费用率高的企业注重技术创新

---

### 6️⃣ ROA趋势与环比变化

**左Y轴（红色）**：ROA（总资产收益率，%）
- 衡量公司全部资产的使用效率
- ROA = 净利润 / 总资产

**右Y轴（灰色）**：环比变化（%）
- 🟢 绿柱 = ROA提升
- 🔴 红柱 = ROA下降

**分析要点**：
- ROA越高，资产利用越有效
- 对比ROE和ROA可以分析公司的财务杠杆使用情况

## 🎯 如何快速读图

### 1. 先看折线（绝对值水平）
- 折线向上 → 指标改善
- 折线向下 → 指标恶化
- 折线平稳 → 指标稳定

### 2. 再看柱状（变化速度）
- 🟢 **连续绿柱** → 持续改善，势头良好
- 🔴 **连续红柱** → 持续恶化，需要警惕
- 🟢🔴 **交替出现** → 波动较大，不够稳定

### 3. 综合判断
| 折线趋势 | 柱状颜色 | 综合评价 |
|---------|---------|---------|
| ↗️ 上升 | 🟢 绿色 | ⭐⭐⭐ 优秀：指标改善且加速 |
| ↗️ 上升 | 🔴 红色 | ⭐⭐ 良好：指标改善但放缓 |
| → 平稳 | 🟢 绿色 | ⭐⭐ 稳定：开始改善 |
| → 平稳 | 🔴 红色 | ⭐ 警惕：开始恶化 |
| ↘️ 下降 | 🔴 红色 | ❌ 风险：持续恶化 |

## 💡 使用技巧

### 技巧1：横向对比
- 观察所有图表中同一季度的表现
- 例如：营收增长但净利率下降 → 可能薄利多销

### 技巧2：纵向追踪
- 观察单个指标跨季度的变化趋势
- 例如：ROE连续4个季度上升 → 盈利能力持续改善

### 技巧3：关联分析
- **营收 vs 净利率**：增收是否增利？
- **毛利率 vs 费用率**：利润来自定价还是费用控制？
- **ROE vs ROA**：高ROE是否依赖高杠杆？

### 技巧4：异常识别
- 某个季度突然出现大幅红柱 → 需查看原因
- 折线和柱状背离（如收入上升但增速下降）→ 需关注持续性

## 📐 图表技术说明

### 设计参数
- **图表尺寸**：18英寸 × 14英寸
- **分辨率**：150 DPI
- **布局**：3行2列子图
- **字体**：支持中文显示（Arial Unicode MS / SimHei）

### 颜色方案
- **折线颜色**：每个指标使用独特颜色以便识别
- **柱状颜色**：
  - 绿色 `#2ca02c` - 正增长
  - 红色 `#d62728` - 负增长
  - 透明度 40% - 避免遮挡折线

### 轴标签
- **左Y轴**：使用指标颜色，标注单位
- **右Y轴**：灰色，标注"环比增长率 (%)"
- **X轴**：季度标签，45度旋转

## 🔍 常见问题

**Q: 为什么有些柱状图没有显示？**
A: 因为该季度缺少上一季度的数据，无法计算环比。通常最旧的季度会缺少环比。

**Q: 为什么有些折线不连续？**
A: 该季度数据缺失（NaN），脚本会自动跳过缺失数据点。

**Q: 如何保存图表？**
A: 图表自动保存在 `fundamental_results/` 目录，文件名格式：`股票代码_时间戳_trends.png`

**Q: 可以自定义图表样式吗？**
A: 可以修改脚本中 `plot_trends()` 方法的参数，调整颜色、尺寸等。
